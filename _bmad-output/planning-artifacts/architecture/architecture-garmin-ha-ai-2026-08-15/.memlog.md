- (constraint) Target platform is Home Assistant Core custom component located in custom_components/garmin_ha_ai/
- (constraint) Garmin Connect authentication and metric fetching must use python-garminconnect with OAuth token persistence in HA .storage
- (decision) AD-1: Layered Adapter architecture with DataUpdateCoordinator and pluggable ai_engine Strategy pattern
- (decision) AD-2: Local JSON snapshot store in HA .storage defaulting to 30 days retention, configurable via Options Flow
- (decision) AD-3: Dual Native Driver AI Engine using google-genai for Gemini and httpx for OpenAI-compatible endpoints
- (decision) AD-4: OAuth token persistence in HA .storage/garmin_ha_ai_tokens.json with Config Flow MFA step and ConfigEntryAuthFailed re-auth handling
- (decision) AD-5: Single DataUpdateCoordinator with extra_state_attributes['full_report'] to store long Markdown health reports safely within HA state limits
- (decision) AD-6: Service garmin_ha_ai.ask_question supports direct service response (SupportsResponse.OPTIONAL), grounded in local 7-day metric snapshots
- (version) python >= 3.12; homeassistant >= 2024.1.0; garminconnect >= 0.3.10; google-genai >= 1.0.0; httpx >= 0.27.0
