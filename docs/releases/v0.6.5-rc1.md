# Release Notes: Garmin HA AI v0.6.5-rc1

**Release Date:** 2026-08-22  
**Tag:** `v0.6.5-rc1`

Garmin HA AI `v0.6.5-rc1` is a major feature and stabilization milestone that brings together complete end-to-end capabilities: deterministic 7-day trend analytics, dual-mode polling schedules, multi-account isolation for households, dynamic AI model discovery, centralized error resilience, complete German and English localization, and an out-of-the-box custom Lovelace card suite with interactive Q&A capabilities.

---

## 🌟 Key Highlights & Major Features

### 1. 📊 7-Day Trend Analytics & Deterministic Baselines (`analytics.py`)
- **Rolling Statistical Means**: Automatically calculates 7-day moving averages for Sleep Score, Resting Heart Rate, Average Stress, Step Count, and Total Calories.
- **Mathematical Goal & Baseline Deltas**: Pre-computes exact numeric variances against personal targets and moving averages (e.g. `+1,200 steps vs avg`, `+5 pts vs sleep target`), eliminating LLM arithmetic hallucinations.
- **HRV Recovery Classification**: Synthesizes multi-day HRV transitions into standardized qualitative stages (`Stable & Balanced`, `Improving`, `Declining`, `Low`).
- **Rich Activity Ingestion**: Ingests aerobic and anaerobic training effect, average HR, maximum HR, distance, calories, and time-in-zones for workout analysis.

### 2. 🔄 Dual-Mode Polling Cadence Engine
- **Daily Fixed Time**: Schedule daily data extraction and morning AI briefing generation at a fixed time (e.g. `06:00:00`) using Home Assistant's native `TimeSelector`.
- **Periodic Interval**: Alternatively choose periodic background polling intervals (every 1, 3, 6, 12, or 24 hours).
- **On-Demand Manual Refresh**: Instant ad-hoc synchronization via service call `garmin_ha_ai.generate_report` or dashboard button `button.garmin_ai_generate_report` with debounced in-flight locking.

### 3. 👥 Multi-Account & Multi-Member Household Isolation
- **Storage Partitioning**: Partitioned credentials and rolling histories per config entry (`.storage/garmin_ha_ai_tokens_{entry_id}.json` and `.storage/garmin_ha_ai_history_{entry_id}.json`).
- **Dedicated Device Scopes**: Separate Home Assistant device registry entries and unique entity namespaces per Garmin account.
- **Per-User Personas & Goals**: Independent fitness goals, target weights, coaching tone directives, and notification targets per user.
- **Targeted Service Calls**: Services `garmin_ha_ai.generate_report` and `garmin_ha_ai.ask_question` accept an optional `entry_id` parameter to target specific accounts, or run globally across all accounts when omitted.

### 4. 💬 Interactive AI Health Coach & Q&A Engine
- **Service `garmin_ha_ai.ask_question`**: Accepts `question`, `days_history` (1–90, default 7), `response_entity`, and `entry_id` with direct response return support (`SupportsResponse.OPTIONAL`).
- **Zero-Helper Dashboard Entities**:
  - `text.garmin_ai_question`: Direct text input for typing coaching questions.
  - `button.garmin_ai_ask_question`: Submits questions directly to the AI coach.
  - `sensor.garmin_ai_last_answer`: Holds the latest answer with `full_answer`, `question`, and `timestamp` attributes.
  - `select.garmin_ai_report_view` & `sensor.garmin_ai_selected_report`: Dynamic display mode switcher.

### 5. 🎨 Packaged Custom Lovelace Cards (`frontend/garmin-ha-ai-cards.js`)
- Automatically registers 4 custom cards with Home Assistant's UI Card Picker:
  - `custom:garmin-ha-ai-card`: All-in-one flagship card with circular SVG recovery gauges, tabs for Summary vs Deep Markdown report, and an expandable interactive Q&A chat drawer.
  - `custom:garmin-ha-ai-qa-card`: Dedicated interactive Q&A chat interface.
  - `custom:garmin-ha-ai-report-card`: Comprehensive Markdown daily briefing viewer.
  - `custom:garmin-ha-ai-overview-card`: Glance recovery overview with focus highlights.
- Zero manual resource installation required: static HTTP endpoints, `/config/www` fallback copying, `add_extra_js_url`, and Lovelace resource auto-registration.

### 6. 🧠 Dynamic AI Model Discovery
- **Google Gemini SDK**: Dynamic model list discovery querying available Gemini models, defaulting to `gemini-2.5-flash` with built-in fallbacks.
- **OpenAI & OpenAI-Compatible Endpoints**: Queries `/models` endpoint dynamically on custom base URLs (Ollama, LM Studio, vLLM, LocalAI, Groq, OpenAI).
- **Custom Typed Model Names**: Full support for entering arbitrary custom or fine-tuned model identifiers.

### 7. 🛡️ Centralized Exception Taxonomy & 429 Resilience (`exceptions.py`)
- Clean hierarchy rooted in `GarminAIError` (`GarminError`, `GarminAuthError`, `GarminMfaRequired`, `GarminRateLimitError`, `AIEngineError`, `AIEngineQuotaError`, `AIEngineTimeoutError`).
- **HTTP 429 Isolation**: Catches Garmin rate limits gracefully, retaining cached metric data without triggering false authentication failures or purging valid OAuth tokens.
- **Automated Reauth Flow**: Intercepts expired session tokens and prompts native Home Assistant re-authentication.

### 8. 🌐 100% Comprehensive Localization
- Complete English (`en.json`) and German (`de.json`) translations for config flows, options flows, entity names, selectors, and service descriptions.
