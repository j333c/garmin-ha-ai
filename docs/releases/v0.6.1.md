# Release Notes: Garmin HA AI v0.6.1

**Release Date:** 2026-08-22  
**Tag:** `v0.6.1`

Garmin HA AI v0.6.1 is a targeted patch release that resolves runtime issues in the packaged Lovelace custom card (`custom:garmin-ha-ai-card`), ensuring smooth initial rendering, resilient entity matching, and robust interactive Q&A reactivity.

---

## 🐛 Bug Fixes & Enhancements

### 1. 🎨 Packaged Custom Lovelace Card (`custom:garmin-ha-ai-card`)
- **Resolved `_parseNumericState` TypeError:** Added `_parseNumericState(entityId)` and `_handleCallService(domain, service, serviceData)` helper methods to `GarminCardBase`.
- **Resilient Entity Matching:** Made `smartFindEntity(hass, patterns, domain)` polymorphic and tolerant to argument ordering variations, preventing "Unknown entity selected" during initial card initialization.
- **Improved Loading & Null State Handling:** Circular gauges gracefully render neutral backgrounds (`rgba(128,128,128,0.4)`) and `"--"` values before initial state payloads arrive or when sensors are unavailable.
- **Enhanced Chat Drawer Reactivity:** Added dynamic "Thinking..." loading feedback and direct response binding on question submission.
- **Automatic Content Reactivity:** Implemented `_updateContent()` on `GarminHAIPackagedCard` to re-render automatically on `hass` state updates without needing manual page reloads.
