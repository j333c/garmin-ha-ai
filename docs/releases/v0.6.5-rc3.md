# Release Notes: Garmin HA AI v0.6.5-rc3

**Release Date:** 2026-11-06  
**Tag:** `v0.6.5-rc3`

Garmin HA AI `v0.6.5-rc3` resolves a critical authentication issue affecting users with Garmin Two-Factor Authentication (MFA) enabled. In previous versions, entering the 6-digit verification code in the Home Assistant setup wizard failed with `"Invalid 6-digit MFA passcode. Please try again."`, immediately triggering a second verification email and an endless loop. This release implements official decoupled session resumption via `garminconnect>=0.3.20`, ensuring seamless MFA authentication and persistent session token generation.

---

## 🌟 Key Highlights & Bug Fixes

### 1. 🔐 Garmin MFA Decoupled Session Resumption (`garmin_client.py`, `exceptions.py`)
- **Root Cause Resolution**: `python-garminconnect`'s `Garmin.login()` does not accept `mfa_code` as an argument; re-instantiating the client created a fresh SSO challenge that invalidated the previous passcode and sent a duplicate verification email.
- **Decoupled State Capture**: The integration now initializes credential authentication with `return_on_mfa=True`. When Garmin SSO challenges for two-factor verification, the client captures the serialized `client_state` payload and surfaces it safely via `GarminMfaRequired`.
- **Session Resumption**: When the user enters their 6-digit passcode in Home Assistant, the integration resumes the active authentication challenge using `client.resume_login(client_state, mfa_code)` without re-submitting credentials or generating redundant MFA challenges.
- **Dependency Bump**: Upgraded underlying `garminconnect` requirement in `manifest.json` to `>=0.3.20`.

### 2. 🧙‍♂️ Config Flow & Re-Authentication State Management (`config_flow.py`)
- **In-Memory State Preservation**: Stores `_mfa_client_state` in-memory across the two-step wizard (`async_step_user` / `async_step_reauth_confirm` to `async_step_mfa`).
- **Session Cleanup**: Automatically clears `_mfa_client_state` upon successful entry creation or re-auth completion to prevent stale session cookies.
- **Fail-Fast Error Handling**: Submitting an MFA code without an active session state or with an invalid code fails fast with `ConfigEntryAuthFailed` instead of silently retrying or triggering new emails.

## 📦 Upgrade Notes

- Upgrades from `v0.6.5-rc2` and prior versions are fully backward-compatible.
- If you previously experienced issues setting up your Garmin account with MFA enabled, you can now complete the setup or re-authentication flow directly in **Settings → Devices & Services → Add Integration → Garmin HA AI**.
