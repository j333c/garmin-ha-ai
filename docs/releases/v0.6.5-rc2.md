# Release Notes: Garmin HA AI v0.6.5-rc2

**Release Date:** 2026-10-09  
**Tag:** `v0.6.5-rc2`

Garmin HA AI `v0.6.5-rc2` is a major reliability, internationalization, and ingestion enhancement release. It introduces configurable multilingual AI response generation (supporting English, German, French, Spanish, Italian, and Dutch or Home Assistant system language auto-detection), a robust 24-hour sliding sync window reconciliation engine to eliminate midnight/early-morning data gaps, historical biometric fallback carryovers (for body weight, composition, and sleep scores), strengthened entity state length clamping, and expanded documentation covering AI workout generator architecture and dashboard usability overhauls.

Special thanks to **[@urbanfrank](https://github.com/urbanfrank)** for dedicated testing, hands-on feedback, and real-world validation!

---

## 🌟 Key Highlights & Major Features

### 1. 🌐 Configurable AI Response Language Preference (`options_flow.py`, `prompt.py`)
- **Language Selector in Options Flow**: Easily configure the preferred target language for all AI outputs via a dropdown selector (`system`, `en`, `de`, `fr`, `es`, `it`, `nl`).
- **Dynamic HA System Language Auto-Detection**: When set to `system` (default), the integration automatically queries `hass.config.language`, dynamically resolving the user's primary interface language with graceful fallback to English.
- **Multilingual Prompt Directives**: Block 5 briefing instructions and interactive Q&A instructions strictly enforce response delivery in the resolved language, explicitly requesting translated Markdown section headers (e.g., German, French, Spanish, Italian, Dutch).
- **Flexible Locale Parsing**: Seamlessly resolves 2-letter ISO codes (`de`, `fr`), full English names (`German`, `French`), native language names (`deutsch`, `français`, `español`, `italiano`, `nederlands`), and regional locale tags (`de-DE`, `fr-CA`, `es_ES`).
- **Options Flow Pre-Population**: Properly reflects and pre-selects existing configured language preferences when re-opening integration options.

### 2. 🔄 24-Hour Sliding Sync Window Reconciliation (`coordinator.py`)
- **Multi-Day Boundary Reconciliation**: Implements a 24-hour sliding window query reconciling metrics across both yesterday and today.
- **Data Gap Prevention**: Eliminates edge cases where morning sync runs executed before new daily sleep or activity aggregation completed on Garmin Connect servers.

### 3. ⚖️ Biometric & Sleep Score Historical Fallbacks (`garmin_client.py`)
- **Historical Weight & Body Composition Carryover**: When today's weigh-in has not yet occurred, the client automatically carries over the most recent logged weight and body composition data (up to 30 days) to prevent missing gauge metrics.
- **Sleep Score Previous-Night Fallback**: If today's sleep score endpoint has not yet computed, automatically falls back to the previous night's score.
- **Body Battery Endpoint Resilience**: Automatically falls back to daily summary metrics if the direct `get_body_battery` endpoint is temporarily unavailable or returns incomplete payloads.
- **Expanded Activity Window**: Ingests activities across an expanded 24-hour window to ensure evening and late-night workouts are fully captured.

### 4. 🛡️ State Clamping & Test Suite Hardening
- **Strict <=250 Character State Truncation**: Enforced defensive boundary checks and ellipsis truncation across foreign language short summaries to ensure entity states never exceed Home Assistant's strict 255-character limit, while preserving complete Markdown reports in attributes.
- **Storage Fixture Hardening**: Corrected time-dependent test fixtures in `tests/test_storage.py` for fully deterministic test execution across any system time and timezone.

### 5. 📚 Comprehensive Architecture & Feature Documentation
- Added detailed design documentation for upcoming AI workout generation and Garmin device sync architecture (`docs/ai_workout_generator_and_device_sync.md`).
- Added comprehensive AI language preference specification (`docs/ai_language_and_preferences.md`).
- Added dashboard usability overhaul specifications (`docs/dashboard_usability_and_cards.md`).

## 📦 Upgrade Notes

- Upgrades from `v0.6.5-rc1` and prior versions are fully backward-compatible.
- To configure your AI response language, navigate to **Settings → Devices & Services → Garmin HA AI → Configure** and select your preferred language under **AI Response Language**.
- Browser cache refresh (`Ctrl+Shift+R` or clearing Companion App frontend cache) is recommended to ensure the updated custom Lovelace card assets are loaded.
