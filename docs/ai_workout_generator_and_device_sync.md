# AI Workout Generator & Garmin Device Sync Guide

## Overview

The `garmin-ha-ai` integration includes an intelligent workout generator that bridges AI health insights and Garmin's physical hardware ecosystem. By leveraging user goals, current readiness (HRV status, Body Battery, Sleep Score), and rolling historical training load, the integration generates tailored, structured workouts and pushes them directly to Garmin Connect via `upload_workout()`. 

Once uploaded, the workout automatically syncs over Bluetooth or Wi-Fi to Garmin watches (Forerunner, Fenix, Epix, Enduro, Venu) and bike computers (Edge), allowing users to execute guided interval targets directly from their wrist or handlebars.

The AI engine uses structured system prompting to synthesize daily recovery metrics into appropriate workout recommendations and format them into valid JSON.

```markdown
### ATHLETE CURRENT METRICS:

- Readiness / Recovery: High
- Sleep Score: 88 (Deep: 1h 45m, REM: 2h 10m)

- Body Battery: 92 (Recharged +64 overnight)
- Resting HR: 48 bpm
- Yesterday's Training: Rest Day (0 active calories)
- Primary Goal: 10km Marathon Preparation, Target 45:00

### INSTRUCTIONS:

   - 5 interval repeats (800 meters at Zone 4/Threshold pace with 2 minutes active recovery)
   - 10-minute cool-down in Zone 1
3. Output the exact Garmin Connect Workout JSON enclosed within ```json ... ``` tags.
```

## Home Assistant Services

The integration exposes `garmin_ha_ai.create_workout` to enable automation-driven or on-demand workout generation.

### Service: `garmin_ha_ai.create_workout`

| Parameter | Type | Required | Description | Default |
| :--- | :--- | :--- | :--- | :--- |
| `sport_type` | string | No | `running`, `cycling`, `strength`, `swimming`, or `cardio` | `running` |
| `workout_type` | string | No | `auto` (AI determines from recovery), `intervals`, `endurance`, `recovery`, `tempo` | `auto` |
| `target_duration_min` | integer | No | Desired workout duration in minutes | 45 |
| `custom_instructions` | string | No | Additional directives (e.g. "Focus on hill sprints" or "Keep heart rate below 140") | `""` |
| `upload_to_garmin` | boolean | No | Whether to push the workout directly to Garmin Connect | `true` |

### Service Call Example (YAML)

```yaml
action: garmin_ha_ai.create_workout
data:
  sport_type: running
  workout_type: auto
  target_duration_min: 50
  custom_instructions: "I have access to an athletic track today. Make it track intervals."
  upload_to_garmin: true
```

### Automation Example: Morning Workout Creation on Alarm Dismissal

```yaml
alias: "Morning AI Workout Generation"
description: "Generates daily workout when morning alarm is dismissed and recovery is high"
trigger:
  - platform: time
    at: "06:45:00"
condition:
  - condition: numeric_state
    entity_id: sensor.garmin_sleep_score
    above: 75
action:
  - action: garmin_ha_ai.create_workout
    data:
      sport_type: running
      workout_type: auto
  - action: notify.mobile_app_phone
    data:
      title: "🏃 New Garmin Workout Ready"
      message: "Your AI Coach pushed today's interval workout to your Garmin watch. Check your watch under Training > Workouts!"
```

## Executing on Garmin Devices

1. Once uploaded, Garmin Connect marks the workout with a unique `workoutId`.
2. Sync your Garmin device via Garmin Connect Mobile (Bluetooth) or Wi-Fi.
3. On your watch:
   * Select activity: **Run** or **Bike**
   * Long-press **Menu** (or tap **Up**) -> **Training** -> **Workouts**
   * Select your custom **AI Threshold 5x800m Intervals** workout
   * Select **Do Workout**
4. Your watch will buzz and guide you through every warm-up, interval step, and rest period with real-time target gauges!
